# DASKIES website (daskies.com)

Static site hosted on Netlify. Every change pushed to `main` goes live automatically.

- `index.html` – the whole site (English). `/members` shows only the full-details listing form for approved members.
- `i18n/` – Hindi, French, German and Spanish translations, loaded when a visitor picks a language (or automatically from their browser language).
- Forms (registration, buyer groups, full listing, services, digest) are collected by Netlify Forms.
